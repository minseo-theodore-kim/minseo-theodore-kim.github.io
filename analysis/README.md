# analysis

The R project behind the pieces on the site goes here.

Copy the contents of the `theodore-on-sport` RStudio project into this folder so
that it looks like this:

```
analysis/
  theodore-on-sport.Rproj
  analysis.R
  data/          one FBref CSV per season
  figures/       charts the script writes
  output/        league-season-summary.csv
```

Keeping the analysis in the same repository as the site means a reader who
follows the link from a piece lands on the exact code and data that produced
its figures.
